LightFoxLauncher

零依赖 · 原生 Win32 · 单文件 <1 MB · 自带联机

用纯 Rust 手写的 Minecraft 启动器：不引第三方库，不登录，不上报，一个 exe 放进文件夹就能用。0.4.1 起内置联机，和朋友直连开服无需中央服务器。

特性

零第三方依赖

JSON、ZIP、DEFLATE、SHA-1、HTTP 全部纯 Rust 手写实现，不引入任何第三方 crate。代码量小，可审计性强。

原生 Win32 GUI

直接调用 Win32 API 绘制界面，不打包浏览器内核，不依赖运行时，内存占用极低，启动瞬间完成。

联机（和朋友一起玩）

0.4.1 新增：开服自动加防火墙规则并尝试端口映射（UPnP 失败回落 NAT-PMP）。IPv6 直连优先，即便在 CGNAT / 对称 NAT 下也能直连。6 位房间号代替 39 位 IPv6 地址，10 分钟有效，无需读出一长串数字。

离线单机与直连

无登录、无认证、无账号体系：不接入任何 Mojang / 微软账号，离线模式即可进服；联机也是点对点直连，不经过任何中央服务器。

MPL-2.0 开源

源代码完全公开，基于 MPL-2.0 许可证发布，欢迎阅读、修改与反馈。

无遥测、无内置服务器

不上传任何数据，不内嵌任何服务端组件。通知接收默认关闭，是否启用由你决定。

联机怎么用

  1. 在启动器「联机」页点 检测网络，它会只读地告诉你本机有哪些可托管地址（公网 IPv6、IPv4 网关、防火墙规则是否已存在），不会改动任何设置。
  2. 点 开服：启动器先加一条入站防火墙规则，再尝试把端口映射出去（UPnP IGD 优先，找不到网关才回落 NAT-PMP）。
  3. 点 建房号 生成一个 6 位房间号（避开 I/0/1 等易混字符），朋友在「用房间号连接」里输入即可，10 分钟内有效。
  4. IPv6 直连优先：只要本机有公网 IPv6，就推荐直接公布 IPv6 地址，绕开 NAT 与随机外网端口，CGNAT 网络下也能联机。

说明：启动器仅支持离线模式，开服会把服务器暴露给知道地址的人；生成的服务端配置已默认开启白名单，请只把地址发给朋友。

通知服务器使用说明

LightFoxLauncher 支持接收公告与新版本提示：在启动器的「通知」页地址框中填入一个 URL，启动器会定时 GET 该地址并展示公告内容。

把下面这个地址粘贴进去即可：

https://lightfoxlauncher.pages.dev/feed.json

  • 该地址由本站托管，站点更新即公告更新，无需重新下载启动器。
  • 启动器默认不启用通知功能，首次启动时会询问你是否开启——不开就完全不会发起请求。
  • 通知内容只用于展示，启动器不会自动执行其中的任何链接。
