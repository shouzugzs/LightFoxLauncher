LightFoxLauncher

零依赖 · 原生 Win32 · 单文件 <1 MB

用纯 Rust 手写的 Minecraft 启动器：不引第三方库，不登录，不上报，一个 exe 放进文件夹就能用。

前往 Releases 下载 配置通知

特性

零第三方依赖

JSON、ZIP、DEFLATE、SHA-1、HTTP 全部纯 Rust 手写实现，不引入任何第三方 crate。代码量小，可审计性强。

原生 Win32 GUI

直接调用 Win32 API 绘制界面，不打包浏览器内核，不依赖运行时，内存占用极低，启动瞬间完成。

离线单机

无登录、无认证、无账号体系。只为离线单机设计，填个用户名就能进世界。

通知服务器使用说明

LightFoxLauncher 支持接收公告与新版本提示：在启动器的「通知」页地址框中填入一个 URL，启动器会定时 GET 该地址并展示公告内容。

把下面这个地址粘贴进去即可：

https://lightfox.pages.dev/feed.json

  • 该地址由本站托管，站点更新即公告更新，无需重新下载启动器。
  • 启动器默认不启用通知功能，首次启动时会询问你是否开启——不开就完全不会发起请求。
  • 通知内容只用于展示，启动器不会自动执行其中的任何链接。
