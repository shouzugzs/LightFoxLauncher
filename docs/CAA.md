# LightFoxLauncher Contributor Assignment Agreement (CAA)

**Status: DRAFT — not yet in force. See [`CONTRIBUTING.md`](../CONTRIBUTING.md) §3.**

Thank you for your interest in contributing to LightFoxLauncher (the "Project").

This Contributor Assignment Agreement ("Agreement") assigns the copyright in your
contributions to the Project's copyright holder. It is adapted from the Harmony
Contributor Assignment Agreement (HA-CAA-I-any, outbound = MIT), re-pointed at the
Project's actual outbound licence, **MPL-2.0**.

> **Why assignment and not a plain licence?** The Project is dual-licensed in
> practice: the source is MPL-2.0, but the maintainer may need to relicense the
> work as a whole (for example to adopt a future MPL version, or to resolve a
> licence-compatibility problem). A bare inbound licence such as the DCO cannot
> grant that, because it leaves each contributor holding a veto. Assignment
> concentrates the rights in one place so the Project can be defended and
> relicensed without tracking down every past contributor.

published at the repository you are contributing to.

holder of the Project in the `Copyright (c)` line of the Project's source files.

modifications or additions to an existing work, that You intentionally submit to

form of electronic, verbal, or written communication sent to the Project or its
representatives, including but not limited to pull requests, patches, issues,
and messages on project mailing lists or chat channels, excluding communication
that is conspicuously marked or otherwise designated in writing by You as
"Not a Contribution".

## How to submit

1. Fill in and sign the table above (typed name is accepted).
2. Email a PDF or plain-text copy to the maintainer address published in the repository description or the latest release notes, with the subject
   line `CAA: <your GitHub username>`.
3. Open the pull request. The maintainer records your name in
   [`CONTRIBUTORS.md`](../CONTRIBUTORS.md) once the CAA is on file.

You only need to do this once; it covers all future contributions to the Project.

The submission address is published in the release notes of the version that opens
contributions, not in this repository — see `PRIVACY.md` for why.
